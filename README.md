# Vesper

在 [Scripting](https://scripting.fun) 裡跑的漫畫閱讀器，**直接使用 Venera 的漫畫源**（源檔不改）。

## 功能

- **源**：加入源倉庫（索引網址）後保存管理，再從倉庫裡挑選要安裝的源。
- **瀏覽**：每個源一頁，導覽列右上拉下選單切「探索 / 分類 / 排行」（分類與排行只在源自己有宣告時才出現）。分類是源宣告的分類與標籤 chips，點進去上面是源宣告的篩選列（`categoryComics.optionList`／`optionLoader`）；排行是源的排行榜（日 / 週 / 月…）。
- **詳情**：支援多語言與卷冊的**章節分組切換**（如 MangaDex）；提供來源網站原始網址開啟（Safari 獨立按鈕）、喜愛數（粉紅愛心膠囊）與相關推薦漫畫橫向海報列。
- **搜尋**：跨所有已啟用源聚合，結果按源分組不混排，側邊欄即時顯示各源結果數。選了單一源會在結果上方多一顆「篩選」，裡面是那個源自己的 `search.optionList`（排序／分類／評級…）；選擇會記住，改完只重跑那一個源。
- **閱讀**：畫廊（一次一頁）與連續（平滑捲動）兩種模式，各有左到右／右到左／上到下三種方向；在閱讀器頂部 HUD 的系統齒輪選單切換，設定會記住。目錄按鈕位於頂部右側，支援章節分組切換（半屏抽屜），且換話嚴格限制於同組內；底部 HUD 採緊湊流線膠囊。章末有「下一章」卡。正文圖片走記憶體（往前 3 頁預取、不落地），只有縮圖落地。
- **留言**：源有提供留言時，詳情頁多一個「留言」入口；點進去是留言列表（頭像、名字、時間、內容，富文本與圖片都渲染）與底部輸入框（一律顯示；送不出去時照源的原話顯示失敗訊息，不假裝成功）。留言不落地，每次進來都重新讀。
- **離線閱讀**：章節區塊可進「選取」勾章節下載，或按「下載全部」抓還沒下載的章節；章節列直接顯示「已下載 / 下載中 x/y / 未完成 x/y / 未下載」。設定頁的「下載」頁列出進行中、未完成與已下載的章節（可取消、可刪除）與離線總佔用，並有「允許背景續傳」開關（Scripting Pro 才有作用）。
- **首頁**：繼續閱讀的橫向卡片（點一下直接回上次讀到的那一頁），加上 Bangumi 的三列「熱門新作 / 大家在追 / TOP 100」（點進去是條目詳情，再跨源聚合可讀的來源）。
- **書架**：收藏（三欄網格）與閱讀歷史。歷史記到「第幾章的第幾頁」，顯示相對時間與進度條，**點一下直接續讀**，左滑刪除。
- **除錯**：內建日誌頁（請求、逾時、重試、各層的診斷都記在這裡）。
- **本地化**：繁中／簡中／英文三語，設定頁可切換（預設跟隨系統）。介面字全部走 `i18n/` 集中管理。

## 用法

1. 執行腳本，開場會詢問**檔案存取**權限——源與書架都存在 `文件/Vesper/` 底下。
2. **設定 → 漫畫源 → 源倉庫 → 加入倉庫**，貼上索引網址；點進倉庫，挑選要安裝的源即可。
   社群索引：`https://raw.githubusercontent.com/venera-app/venera-configs/main/index.json`
3. 需要登入的源：**瀏覽 → 選源 → 詳情 → 登入**。帳密與 Cookie 欄位的憑證存在 iOS Keychain；
   有些源（例如 `mycomic` 的 Cloudflare 過盾）要**在瀏覽器裡登入**——按下去會開一個瀏覽器視窗，登入完自動關掉。
4. **自架伺服器**（Komga / Kavita / Lanraragi）要先在**詳情 → 源設定**填自己的伺服器位址。
5. **瀏覽**選源開始看，或用**搜尋**跨源找。

## 相容性

支援 Venera 源的主要功能：探索、分類、排行、搜尋、留言、離線閱讀、登入（帳密／Cookie／瀏覽器）。

已知限制：
- Cloudflare 自動過盾（源可以宣告 `loginWithWebview` 讓使用者手動過一次）
- 源端收藏與評分寫入（刻意不做：用不到）
- 網路層的 `http_client`／`prevent-parallel`／`cache-time` 選項（統一走 `fetch`，實測主要源都正常）

## 執行與相依

在 [Scripting](https://scripting.fun) App 內直接開啟專案執行（進入點為 `index.tsx` 或首頁元件 `home_screen_default_ui.tsx`）。

依賴套件：
- `cheerio`（HTML 解析）
- `crypto-js`（AES-ECB 備援解密）
